# PDFree

Free PDF editor that runs entirely in your browser. Nothing is uploaded.

- **Edit**: change existing text, add text, draw, highlight, white out, add images
- **Organize**: merge, reorder, rotate, delete, extract pages; turn images into PDF pages

```bash
npm install
npm run dev     # http://localhost:3000
npm run check   # self-check for the PDF logic
```

Built with Next.js, pdf-lib and pdf.js. Fonts in `public/fonts` are Liberation fonts (SIL OFL, see `public/fonts/LICENSE`).
